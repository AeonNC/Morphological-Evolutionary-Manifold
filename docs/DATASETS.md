# Dataset feasibility notes (Stage 0)

Research Use Only. MEM is a computational research framework and is not validated for clinical diagnosis, treatment selection, molecular profiling, clonal lineage reconstruction, or minimal/measurable residual disease reporting.

No public dataset is approved for training in Stage 0. Adapters are Stage 1. Official URLs, licenses, and counts must be verified from the source at acquisition time. Do not use unknown-provenance mirrors for final experiments.

See the Stage 0 report in `docs/STAGE0_REPORT.md`.
